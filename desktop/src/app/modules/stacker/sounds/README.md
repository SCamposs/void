# VOID glacial reference sound pack

These 23 recordings are adapted from TETR.IO's OSK sound atlas. Original audio
ownership remains with OSK; modification does not relicense the recordings.

`provenance.json` records the original URL, source hash, clip names and offsets,
processing parameters and output hashes. Regenerate using
`scripts/prepare_stacker_reference_audio.py` with a local RSD 1.0 atlas and FFmpeg.
The complete original bank and game client are not distributed with this pack.
