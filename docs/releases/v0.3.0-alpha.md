VOID's shared interface now follows the visual foundation established in VOID Mind: black surfaces, glacial-white light, local Urbanist and Barlow typography, and consistent accessible controls.

**Alpha release.** The common shell and controls are updated. Individual refinements to Orbit, Typing, Stacker and the embedded Mind are a subsequent phase.

Each package has an adjacent SHA-256 checksum and updater signature. `latest.json` supplies the signed in-app update metadata, including separate DEB and AppImage routes for Linux. DEB updates use the system package manager and may request administrator authorization.

## Added

- A consistent Base UI foundation for buttons, inputs, selects, toggles, checkboxes, sliders, number fields, tooltips, scrollbars, dialogs and confirmations.
- A quieter Home, compact navigation, keyboard module search (`Ctrl+K`) and Settings shortcut (`Ctrl+,`).
- An integrated VOID titlebar with native window actions and a sidebar that actually returns space to the content when collapsed.
- Locally bundled Urbanist headings and Barlow text/controls, including font licenses.
- VOID icons and artwork for the NSIS installer and uninstaller.

## Changed

- The canonical boot mark now resolves to white, with restrained cold lighting, wordmark motion, Skip/Escape and reduced-motion support.
- Updates are checked when the app opens and every hour. Settings can switch to manual checks only.
- A VOID dialog announces available updates, asks for permission to update and restart, and shows download progress. Choosing Later keeps the current version running; the same version does not repeatedly reopen the dialog during that session.
- Windows updates use quiet installation for the current user, avoiding the install-scope selection screen. The app closes during installation and restarts afterward.

## Fixed

- Keyboard access to backup and manifest import actions.
- Selector focus and rapid accented keystroke capture in Typing.
- Shared focus states, dark select popups, disabled cursors and game-shortcut isolation while using form controls/dialogs.
- Update failure handling: failed downloads remain retryable, and failed restarts can be retried without downloading/installing again.

## Removed

- The obsolete global **App appearance** customization. Saved legacy appearance values no longer alter the new fixed identity. Existing local data is not deleted by this change.

## Installation and known limitations

- Windows packages are **not Authenticode-signed**; SmartScreen may display a warning. Updater signatures are separate and protect in-app updates. Download only from this repository and verify the adjacent checksum.
- The new manual/automatic preference and branded update dialog become available after installing this version. Older installations retain their existing update interface until upgraded.
- Native window/DPI behavior, real upgrade/restart behavior and final installer acceptance still require [manual validation (#2)](https://github.com/SCamposs/void/issues/2). Windows code signing is tracked in [#1](https://github.com/SCamposs/void/issues/1).
- This release does not port standalone VOID Mind's ChatGPT login or API-key connections into the embedded Mind, and does not add plugins or new AI features.

## Verification

The shared foundation passed automated lint, TypeScript, unit tests, isolated Chromium interaction tests and Windows candidate packaging. The tagged release workflow independently validates and packages Windows NSIS and Linux DEB/AppImage assets. Automated checks do not replace the manual acceptance items above.
